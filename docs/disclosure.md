# Confidentiality and provenance

## Publication boundary

This portfolio contains a newly written, generalized description of internship activities. It excludes company-specific identifiers, employee names, sites, exact internal metrics, event timelines, raw or transformed telemetry, enterprise records, internal code, warehouse schemas, credentials, presentation materials, and trained artifacts.

Anonymization reduces exposure but does not itself establish permission to disclose. Approval to read a private source also does not authorize publishing it. Company-approved disclosure requirements take precedence over the generic presentation of this repository.

## Excluded claims

The repository does not assert production readiness, reliable physical failure prediction, verified warning lead time, savings, downtime reduction, measured LLM improvement, broader generalization, or independent reproduction of internal results.

## Future additions

Use an independently written explanation or a wholly synthetic example rather than an export, screenshot, cleaned notebook, or redacted document from an internal system. Check derived artifacts as carefully as raw data: plots, model weights, logs, filenames, and notebook outputs can reveal internal information.

Keep any restricted review notes outside the repository and its Git history. If a disclosure requires company approval, obtain that approval before including it in a public commit. Public documentation practices are a format reference, not a substitute for authorization.

## Rights

No employer-owned code or artifacts are licensed through this repository. No open-source license has been selected for the newly authored portfolio materials; a license should be added only after the author chooses it and verifies the rights to the covered material.
