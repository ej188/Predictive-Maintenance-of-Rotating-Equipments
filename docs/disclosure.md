# Confidentiality and provenance

## Publication boundary

This portfolio contains a newly written, generalized description of internship activities. It excludes company-specific identifiers, employee names, sites, additional internal metric summaries, event timelines, raw or transformed telemetry, enterprise records, internal code, warehouse schemas, credentials, presentation materials, and trained artifacts.

Two specifically approved figure treatments are included as a narrow exception: anonymized feature importance and predictions versus a constructed RUL reference. They retain original bar lengths, point distributions, numeric scales, and units; no normalization or point manipulation is performed. The author instructed their public release after review of that scope. This is author-provided release authorization, not an independently audited employer clearance.

Anonymization reduces exposure but does not itself establish permission to disclose. Approval to read a private source also does not authorize publishing it. Company-approved disclosure requirements take precedence over the generic presentation of this repository.

## Excluded claims

The repository does not assert production readiness, reliable physical failure prediction, verified warning lead time, savings, downtime reduction, measured LLM improvement, broader generalization, or independent reproduction of internal results.

## Future additions

Prefer an independently written explanation or a wholly synthetic example. Original internal figures require explicit approval of the particular underlying information being disclosed, followed by a review of the exact final assets. The two approved treatments do not grant blanket permission for additional private artifacts. Check derived artifacts as carefully as raw data: plots, model weights, logs, filenames, and notebook outputs can reveal internal information.

Keep any restricted review notes outside the repository and its Git history. If a disclosure requires company approval, obtain that approval before including it in a public commit. Public documentation practices are a format reference, not a substitute for authorization.

## Rights

Publication of the two treated figures does not grant an open-source license to employer-owned material. No employer-owned code is included. No open-source license has been selected for the newly authored portfolio materials; a license should be added only after the author chooses it and verifies the rights to the covered material.
