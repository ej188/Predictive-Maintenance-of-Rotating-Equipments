# Contributing

Keep changes focused on readable, evidence-backed documentation and independent synthetic examples.

- Label self-reported work, independently reproducible demonstrations, and proposed extensions distinctly.
- Do not add company source material, telemetry, event records, internal screenshots, model artifacts, or credentials.
- Use relative links for repository documents and primary sources for external references.
- Explain what changed and how it was checked. Avoid unsupported impact or deployment claims.
- Run `python3 scripts/check_repository.py` and `python3 examples/evaluation_slices.py` before proposing a change.

The automated check is a narrow aid. It does not establish that a disclosure is authorized or that all sensitive information has been detected.
