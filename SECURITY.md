# Accidental disclosure

Do not post suspected secrets, private records, or sensitive excerpts in a public issue or pull request.

If a credential is exposed, treat it as compromised and arrange revocation or rotation through its owner. Removing a file in a new commit does not remove prior versions. Coordinate with the repository owner and the relevant data owner to contain exposure and address history, caches, and copies as appropriate.

This repository provides no production service and accepts no confidential company artifacts.
